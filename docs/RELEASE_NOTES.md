# 1.0.0-beta.1 · macOS 测试版

下载 `Peashooter-File-Cleaner-1.0.0-beta.1-universal.dmg`，打开后把应用拖进 Applications；不需要 Xcode 或终端。支持 macOS 13+，包含 Apple Silicon 和 Intel 两种架构。

这是 **匿名本地签名、未经 Apple 公证的测试版**，不是无安全提示的正式版。首次打开可能需要在系统设置“隐私与安全性”中明确允许。若系统报告恶意、损坏或没有放行入口，请停止使用并反馈；不要关闭 Gatekeeper/SIP 或执行绕过隔离的命令。参阅安装盘中的 `使用说明.html` 或应用菜单的“安装与使用说明”。

首次使用：

1. 先播放安全演示，不操作真实文件。
2. 点击“设置 Finder 右键菜单…”，按说明手动启用 Finder 扩展；需要时安装兼容快捷操作。
3. 按需允许辅助功能、控制 Finder 和选中文件目录的权限。
4. 对单个普通文件右键“召唤豌豆射手”；经过两次独立确认后才会移入废纸篓。不支持文件夹、应用、符号链接或系统文件。

射手从左侧进入，前四次命中叠加裂纹；第五颗弹丸抵达并且系统废纸篓操作成功后才碎裂。两只僵尸抬担架退场。演示模式不操作真实文件。

隐私：安装包不含发布者的账户凭据、个人路径、截图、日志、授权数据库、证书私钥或调试符号；素材仅打包经过元数据清理的运行资源。应用不内置联网或遥测服务。请勿在问题反馈中直接粘贴私人文件路径或未处理的日志/截图。

限制：未公证；Finder 扩展、快捷操作、系统授权、多显示器和 Finder 图标刷新时序仍需在各目标 Mac 上实测。通用二进制不等于已在 Intel 硬件或所有 macOS 版本上验证。附 `SHA256SUMS.txt` 可校验文件完整性，不代表 Apple 审核或独立安全认证。
