macOS 13+ · Apple Silicon 与 Intel 通用版

豌豆射手文件清理器

在 Finder 或桌面右键召唤，经过两次确认后，射手以动画将选中的单个普通文件送进废纸篓。无需 Xcode、终端或 Apple 开发者账户。

这是未经 Apple 公证的测试版。首次下载打开可能受到 macOS 安全检查限制。只有确认下载来源和校验值可信时才继续；请勿关闭 Gatekeeper、关闭 SIP 或执行移除隔离属性的命令。不能保证每台 Mac 都能放行。

1. 安装与第一次打开

  1. 打开下载的 .dmg，把 Peashooter File Cleaner.app 拖到旁边的 Applications（应用程序）。等待复制完成后推出磁盘映像。
  2. 从“应用程序”双击启动。首次打开应出现控制面板；菜单栏会有叶子图标，之后关掉控制面板仍会后台运行。
  3. 若提示“无法验证开发者”或“无法检查是否包含恶意软件”，先尝试打开一次，再到 系统设置 → 隐私与安全性 查找该应用对应的“仍要打开”。按系统提示自行确认。若被告知恶意、已损坏，或没有允许入口，停止操作并反馈，不要绕过保护。
  4. 先点击 播放安全演示。演示只使用虚拟图标，不会操作真实文件。

2. 打开 Finder 右键入口

  1. 在控制面板或菜单栏叶子菜单中点击 设置 Finder 右键菜单…。
  2. 在系统设置中搜索“扩展”或“Finder”，启用 Peashooter 的 Finder 扩展。较新的 macOS 通常位于 通用 → 登录项与扩展 → Finder；较旧版本可能位于 隐私与安全性 → 扩展 → Finder 扩展。菜单名称随系统变化。
  3. 如果系统不显示顶层菜单，点击应用中的 安装兼容入口，应用会在当前用户的 ~/Library/Services 添加“召唤豌豆射手”快捷操作。它不会覆盖已有同名操作，不会自动授权。到系统设置启用相应快捷操作（部分系统在键盘快捷键的“服务”中）。
  4. 回到 Finder，对“桌面”“文稿”或“下载”中的一个普通文件右键，查找 召唤豌豆射手。兼容入口可能位于 快速操作 或 服务 子菜单。必要时重新打开 Finder，或退出登录再登录。保持应用后台运行有助于记录原始右键位置。

3. 权限与真实使用

为准确对齐真实图标，请在 系统设置 → 隐私与安全性 → 辅助功能 允许此应用；系统询问“控制 Finder”时，由你决定是否允许。首次访问桌面、文稿、下载可能有相应文件权限提示。应用不要求关闭系统保护或无条件授予完全磁盘访问。所有权限都由每位下载者在自己的 Mac 上决定，安装包不含发布者的授权记录。

  1. 只选中一个你确定不需要的普通文件，再右键召唤。不要拿重要文件试用。
  2. 核对文件名、大小与路径，点击“确认是它”。第二次再次核对，再选择“我无比确认，开火！”。任一步取消都不会移动文件。
  3. 第五颗弹丸抵达后才尝试移入废纸篓；系统操作成功后播放最终碎裂。失败会停止最终碎裂并显示错误。角色随后由两只僵尸抬担架离场。
  4. 要恢复文件，打开系统废纸篓使用“放回原处”。本应用不会清空废纸篓、不提供永久删除。

4. 常见问题

  • 双击似乎没有反应：先看菜单栏叶子图标，选择“打开控制面板”；同时检查系统安全提示。应用没有 Dock 常驻窗口。
  • 右键找不到入口：核对扩展开关和“快速操作/服务”子菜单；确认只选了一个普通文件。文件夹、应用、符号链接、系统目录、用户 Library 和应用目录内文件不支持。
  • 提示无法定位：保持 Finder 中只选中目标，授予辅助功能或控制 Finder 权限；不使用点击菜单按钮后的位置，防止错位。重新右键再试。
  • 换版本后权限失效：此测试版使用本地匿名签名，重新构建后可能需要在辅助功能列表中移除旧条目并重新添加应用。Finder 扩展是否加载仍取决于目标系统。

5. 隐私、反馈与卸载

应用不内置账号、联网服务或遥测；不读取文件内容，不将你的文件上传。界面会显示本次选中文件的名称和路径；部分定位错误与诊断由系统日志记录，路径字段按系统隐私规则处理。对外反馈时请只描述现象、系统版本和处理后的错误信息，遮挡姓名、文件名、路径和桌面内容，不要直接公开原始日志或截图。

退出菜单栏中的应用，把应用移到废纸篓；若安装过兼容入口，可在 Finder“前往文件夹”打开 ~/Library/Services，将“召唤豌豆射手.workflow”移入废纸篓。其他文件不要动。
